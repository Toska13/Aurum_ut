# Иерархический отчёт по цепочке заказа

Отчёт по цепочкам — не плоский список «одна строка = заказ» или «одна строка = позиция». Структура дерева: **заказ клиента** → **позиции заказа** → **связанные документы позиции** (заказы поставщику, заказы на сборку и дальше по цепочке). Показатели видны на каждом уровне, где они имеют смысл.

Монитор по одному заказу остаётся отдельным потребителем того же слоя данных; отчёт нужен для обзора по списку заказов с проваливанием в позиции и документы без перехода в монитор.

**Considered Options**: плоский список по заказам; плоский список по позициям без родителя-ЗК — отвергнуты (2026-08-14).
