# Исправление маркировки: связанные строки и разбиение количества

Смена на парную номенклатуру идёт только по текущей строке поступления/ордера и по строкам оснований, связанным с ней (код строки, заказ в строке, номенклатура+характеристика+назначение). Если количество основания больше — строку основания разбиваем, чтобы отгрузка по заказу клиента совпала с купленным. Соседние приходные ордера и прочие строки того же документа с той же номенклатурой не трогаем: кладовщик жмёт кнопку на каждой строке. Это сознательно не «заменить весь товар1 в заказе» и не «подтянуть все ордера ветки».
