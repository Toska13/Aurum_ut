# Приоритет товаров над деньгами и поэтапный контроль ввода

Монитор и отчёт цепочки заказа клиента: пользователю важнее увидеть разрывы по товару (закуплено / принято / отгружено), чем по деньгам. Денежные колонки и сверка с взаиморасчётами — второй слой, не главный смысл экрана.

Контроль ввода (лишний заказ на сборку и аналоги) на первом этапе — только предупреждение без `Отказ`; после обкатки — переход на жёсткую блокировку. Иначе менеджеры не успеют поправить процесс до массовых отказов записи.

**Considered Options**: одинаковый приоритет товар/деньги; сразу блокировка ввода — отвергнуты по решению владельца процесса (2026-08-14).
