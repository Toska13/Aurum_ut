# Монитор цепочки — табличный документ и пути позиции

Монитор одного заказа клиента выводится **табличным документом**, по образцу общей формы `СвязанныеДокументы`: одно поле, дерево с отступом, расшифровка открывает ссылку. Иерархия: заказ клиента → позиции (колонки показателей) → связанные документы позиции → штрихкоды упаковок. Набора `ТаблицаФормы` на форме нет.

На строке позиции заказа клиента колонки этапов не сворачиваются и не обнуляются, когда появляется следующий документ: «в сборке» живёт рядом с «собрано»; «заказано поставщику» — рядом с «приобретено». На одной строке заказа заполняется только одна из двух пар — путь сборки (есть заказ на сборку на это зерно) или путь закупки. Закупка комплектующих не смешивается со строкой комплекта.

**Considered Options**: оставить дерево + четыре таблицы на форме; дерево документов без колонок позиций (метрики только в отчёте); два блока в одном табличном документе (таблица позиций сверху, дерево снизу); обнулять «в сборке» / «заказано поставщику» после сборки / приобретения — отвергнуты (2026-08-17).
