# Раздельные показатели цепочки и остаток без назначения

Показатели по позиции заказа не сворачиваем в агрегаты вроде «отгружено» или «закуплено»: реализация, расходные ордера, приобретение, приходные ордера — отдельные колонки там, где слой данных их собирает. Пользователь сравнивает этапы документов, а не одну свёрнутую цифру.

Остаток на складе при пустом назначении на заказе клиента не обнуляем и не считаем «дырой данных»: в базе есть закупки без назначения, и колонка показывает `ВНаличии` по номенклатуре+характеристике с пустым назначением. При заполненном назначении — отбор по назначению шапки заказа.

Отменённые строки заказа клиента в монитор и отчёт не попадают (позиция не показывается), а не только обнуляют «заказано».

**Considered Options**: одна колонка «отгружено»; пустое назначение = 0 на складе; показывать отменённые с пометкой — отвергнуты (2026-08-14).
